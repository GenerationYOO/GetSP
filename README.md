# GetSP — Planning Poker Platform

**GetSP** — веб-приложение для командной оценки трудоёмкости задач (Planning Poker) с модулем AI-рекомендаций на основе поиска векторизованных эталонных задач и интеграцией с YouTrack / Agile-системами.

---

## Технический стек

* **Backend:** .NET 10 / C# 
* **Frontend:** React 19, TypeScript, Vite
* **UX/UI:** Figma
* **DevOps:** Docker
